# kotlin-lotto-precourse

## 구현할 기능 목록

- [x] 로또 번호의 숫자 범위가 유효한 범위인지 확인한다
- [ ] 당첨 번호의 숫자 범위가 유효한 범위인 지 확인한다
- [x] 로또 번호들이 중복되지 않은 숫자로 구성되었는 지 확인한다
- [ ] 당첨 번호들이 중복되지 않은 숫자로 구성되었는 지 확인한다
- [x] 로또 번호를 정해진 개수만큼 뽑는다
    - 정해진 수량보다 적게 뽑는 경우
    - 정해진 수량보다 많이 뽑는 경우
- [ ] 당첨 번호를 정해진 개수만큼 뽑는다
    - 보너스 번호를 정해진 개수만큼 뽑는다
- [ ] 당첨 번호와 보너스는 중복되지 않았는 지 확인한다
- [ ] 구입 금액이 유효한 단위가 아니라면 예외 처리한다
- [ ] 구입 금액에 해당하는 만큼 로또를 발행한다
- [ ] 로또 번호는 오름차순으로 정렬해 보여준다
- [ ] 예외 상황 시 에러 문구는 `[ERROR]`로 시작한다
- [ ] 당첨 번호와 구매한 로또를 비교해 등수를 확인한다
- [ ] 구매한 로또의 당첨 결과를 판단한다
- [ ] 구매한 모든 로또를 통해 당첨 내역을 출력한다
- [ ] 구매한 모든 로또를 통해 수익률을 출력한다
    - 수익률은 소수점 둘째 자리에서 반올림한다.(ex. 100.0%, 51.5%)

## 결정한 요구 사항

### 1. 당첨 번호와 보너스 번호는 중복되지 않아야 한다.

2등 조건이 5개의 번호 + 보너스 번호 일치입니다.
만약 당첨 번호와 보너스가 중복된다면 보너스 번호 일치 시 5개의 번호가 아닌 6개의 번호가 일치하는 1등이 됩니다.
따라서 1등과 2등을 구분시키기 위해 당첨 번호는 보너스 번호와 중복되어서는 안됩니다.
